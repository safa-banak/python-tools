# Python Tools
A collection of Python and Linux automation scripts for system monitoring and data processing.

## Scripts
- `word_counter.py` – Counts lines and words in a text file.
- `read_servers.py` – Reads and displays server data from a CSV file.
- `high_cpu_report.py` – Filters servers with high CPU usage and saves a report.
- `sysinfo.py` – Collects disk, memory, and uptime info and saves as CSV.
- `system_json.py` – Collects system info and saves as JSON.

## Usage
Run any script with:
```bash
python3 script_name.py
```
